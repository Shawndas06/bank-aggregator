# 🏦 Bank Aggregator - Агрегатор Банковских Счетов

Мощное банковское приложение для агрегации счетов из разных банков, управления финансами, аналитики и совместного семейного бюджета.

## 📋 Описание проекта

Bank Aggregator - это современное веб-приложение, которое позволяет пользователям:

- 🔗 **Агрегировать счета** из нескольких банков в одном месте
- 💰 **Управлять финансами** с детальной аналитикой расходов и доходов
- 👨‍👩‍👧‍👦 **Совместный семейный бюджет** с группами и общими счетами
- 📊 **Аналитика** с прогнозами, рекомендациями и инсайтами
- 💳 **Платежи** - переводы между счетами, оплата услуг, QR-коды
- 🎁 **Премиум функции** - кешбек, программы лояльности, реферальная система
- 📱 **Мобильный интерфейс** с адаптивным дизайном

## 🚀 Технологический стек

### Backend
- **FastAPI** - современный Python веб-фреймворк
- **PostgreSQL** - реляционная база данных
- **Redis** - кэширование и сессии
- **SQLAlchemy** - ORM для работы с БД
- **Docker & Docker Compose** - контейнеризация

### Frontend
- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **React Query** - управление состоянием и кэширование
- **React Router** - маршрутизация
- **TailwindCSS** - стилизация
- **Framer Motion** - анимации
- **Zod** - валидация форм

## 🛠️ Установка и запуск

### Предварительные требования

- **Docker** и **Docker Compose** установлены
- **Node.js** 22.12+ (22.x) и **npm** (для frontend)
- **Python** 3.11+ (опционально, если запускаете backend без Docker)

### Быстрый старт

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd bank-aggregator
```

2. **Запустите Backend (Docker Compose):**
```bash
cd backend
docker-compose up -d
```

Это запустит:
- PostgreSQL на порту `5432`
- Redis на порту `6379`
- FastAPI Backend на порту `8000`

3. **Запустите Frontend:**
```bash
cd frontend
npm ci
npm run dev
```

Frontend будет доступен на `http://localhost:5173`

4. **Проверьте работу API:**
- API: http://localhost:8000
- Swagger Docs: http://localhost:8000/docs
- Health Check: http://localhost:8000/health

## 📖 API Документация

После запуска backend, полная документация API доступна по адресу:
- **Swagger UI**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc

## 🔑 Основные функции

### 1. Агрегация банков
- Подключение счетов из VBank, ABank, SBank
- Синхронизация балансов и транзакций
- Единый интерфейс для всех счетов

### 2. Управление финансами
- Просмотр всех транзакций
- Детальная аналитика расходов и доходов
- Категоризация транзакций
- Фильтрация и поиск

### 3. Платежи и переводы
- Внутренние переводы между счетами
- Переводы на карты (card-to-card)
- Оплата услуг (ЖКХ, интернет, телефония)
- QR-коды для платежей
- Проверка карт перед переводом

### 4. Семейный бюджет
- Создание групп для совместного бюджета
- Общие счета и транзакции
- Приглашения участников
- Управление правами доступа

### 5. Аналитика
- Обзор финансов (доходы, расходы, баланс)
- Топ категории расходов
- Графики и визуализация
- Прогнозы и рекомендации (Premium)
- Продвинутые инсайты

### 6. Премиум функции
- Кешбек и программы лояльности
- Реферальная система
- Карты лояльности
- Дополнительная аналитика

### 7. Безопасность
- Аутентификация через email и пароль
- OTP верификация email
- JWT токены для сессий
- Хеширование паролей (bcrypt)

## 🔧 Конфигурация

### Backend переменные окружения

Основные настройки находятся в `backend/src/config.py` и могут быть переопределены через переменные окружения:

```env
DATABASE_URL=postgresql://postgres:password@postgres:5432/bank_aggregator
REDIS_HOST=redis
REDIS_PORT=6379
SECRET_KEY=your-secret-key
ALLOWED_ORIGINS=http://localhost:5173
```

### Frontend конфигурация

API URL настраивается в `frontend/src/shared/config/constants.ts` и автоматически определяется для локальной и мобильной разработки.

## 📱 Мобильная разработка

Для доступа с мобильных устройств в той же сети:

1. Убедитесь, что frontend запущен с `host: '0.0.0.0'` в `vite.config.ts`
2. Добавьте IP вашего устройства в `ALLOWED_ORIGINS` в backend
3. Используйте IP компьютера вместо `localhost` (например, `http://192.168.0.104:5173`)
